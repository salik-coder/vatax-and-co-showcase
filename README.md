# 💼 VATAX & Co

A professional business website developed for **VATAX & Co**, an accounting and tax services brand.

This repository is a **public showcase only**.  
The production source code and backend remain private.

🌐 **Live Website:** https://vatax.uk

---

## ✨ Project Highlights

- Professional accounting and tax services website
- Responsive desktop, tablet and mobile design
- Clear service presentation
- Business-focused modern UI
- Contact and enquiry experience
- Production deployment with custom domain
- HTTPS-enabled live website
- Frontend and backend integration

---

## 🛠 Tech Stack

- React
- JavaScript
- HTML
- CSS
- Responsive Web Design
- Backend API Integration
- Production Deployment

---

## 🎯 Project Goal

The goal was to create a trustworthy and professional digital presence for VATAX & Co while making its accounting and tax services easy to understand and access.

The project focuses on:

- Clear business communication
- Professional presentation
- Responsive usability
- Real-world deployment
- Maintainable web architecture
